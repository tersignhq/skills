# Tersign Agent Skills

Official agent skills published by [Tersign](https://tersign.ai) — the evidence layer for the agent economy.

| Skill | What it does |
|---|---|
| [`tersign-evidence/`](tersign-evidence/) | Produce, verify, and submit counter-signed transaction evidence: no-trust receipt verification, dispute-ready evidence envelopes (Internet Court / Kleros ERC-1497 / UMA), counter-signed receipt issuance via the `tersign` npm SDK, independently attested agent action and disclosure records. |

MIT licensed. The SDK: [`npm install tersign`](https://www.npmjs.com/package/tersign).
